## 🌌 About

Astramyth is a young engineering team. We take real business problems and turn them into working software, from data pipelines to full-stack platforms. Most of our work is currently done for clients and lives in private repositories, but we'll share what we can here as we grow.

## 🛠️ What we do

- **Backend systems**: APIs and services built with Java and Spring Boot
- **Web applications**: modern frontends with React and TypeScript
- **Data & integration**: converting, moving and validating data between systems (Excel/Word to JSON/XML, file servers, and more)
- **Real estate solutions**: tools for property and listing workflows

## 🧰 Tech we work with

`Java` · `Spring Boot` · `TypeScript` · `React` · `PostgreSQL` · `Docker` · `Git` · `C#` · `.NET` · `Angular`  

## 🚀 Projects

Our current projects are private and built for clients. Public repositories will appear here as we open-source tools and templates.
